## 一、架构设计

### 1.1 分层架构
表现层   | frontend-vue/src/ (views/components/composables/stores/api/types/styles)
接入层   | nginx + controllers + validators + middleware
业务层   | backend/src/services/
引擎层   | backend/src/services/analysis/ (kpiRegistry/industryLoader/dispatcher/normalize)
数据层   | PostgreSQL 16+PostGIS 3 + Redis 7

### 1.2 核心原则
- 单一职责: 每个service文件 <200行
- 数据驱动: 行业参数从DB加载, 支持热更新
- 防御式编程: validator中间件统一校验, try-catch全覆盖
- 测试先行: 先写测试再写实现
- 日志规范: pino结构化日志, 敏感信息自动脱敏
- 阿里规范: 命名/注释/异常处理/SQL参数化/代码格式化
