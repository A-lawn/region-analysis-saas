# 日志与脱敏方案

## 一、当前审计发现

### 问题1: console.* 未迁移到 logger (15处)
apiV1Controller/webController/poiCollector/auth/errorHandler/competitionService/
geocodingService/spatialAnalysis/voronoiService 共9个文件中存在 console.error/warn

### 问题2: 敏感信息泄露 (2处)
emailService.ts:30  logger.info({ to: "user@email.com" })  -- 邮箱明文
emailService.ts:33  logger.error({ to: "user@email.com" }) -- 邮箱明文

### 问题3: 开发环境暴露堆栈给客户端
errorHandler.ts:56  NODE_ENV !== production 时返回 stack 到 HTTP response

### 问题4: 日志无持久化
pino 仅输出到 stdout，容器重启后丢失，无轮转策略

### 问题5: 无请求追踪
无 requestId 注入，无法追踪完整请求链路

## 三、脱敏效果

改前: logger.info({ to: "zhangsan@company.com" }, "Email sent")
改后: logger.info({ to: "***@***.***" }, "Email sent")

改前: console.error("Unhandled error:", err) -- 无requestId无格式化
