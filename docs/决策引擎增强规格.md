# 决策引擎增强完整规格 (9条规则 -> 24+条规则)

## 当前9条规则 (通用, 无量化)

1. low-coverage: gapRatio>30 && pointCount>=3 -> "存在显著服务盲区"
2. random-distribution: noiseRatio>0.3 -> "点位分布随机性较高"
3. high-concentration: isConcentrated && gapRatio>30 -> "服务高度集中"
4. site-strongly-recommend: topSiteScore>0.7 -> "Top1评分较高"
5. site-optional: topSiteScore 0.4-0.7 -> "Top1评分中等"
6. site-not-recommended: topSiteScore<0.4 -> "Top1评分偏低"
7. market-saturated: competitorGapRatio<0.5 && gapRatio<30 -> "市场趋于饱和"
8. market-underserved: competitorGapRatio>2 -> "竞品缺口显著"
9. high-overlap: overlapRatio>50 && pointCount>=3 -> "门店间服务区严重重叠"
10. few-clusters: clusterCount==1 && pointCount>10 -> "所有点位聚集在同一区域"

## 新增规则

### 覆盖分析类 (4条)
11. gap-hotspot: gapRatio>行业阈值 && POI_RES高密度区在uncovered区
    -> "XX-YY 1.2km走廊带无覆盖, 该区域居住密度为项目均值2.1倍"
    处方: 推荐3个候选点填充空白走廊带

12. coverage-benchmark: coverageRatio<行业中位数
    -> "您的覆盖率42%, 行业中位数68%, 行业P75 82%"
    处方: 需新增N家门店可达中位线

13. expansion-impact: 虚拟新增候选点->覆盖提升>15%
    -> "若在XX位置新开门店, 整体覆盖率可从62%提升至78%"
    处方: 显示覆盖模拟对比图

14. seasonal-blind: metadata含月份数据 && 覆盖区有显著季节差异
    -> "夏季覆盖率82%, 冬季降至58%"
    处方: 建议冬季临时增加移动点位

### 竞争分析类 (5条)
15. cannibal-warning: cannibalizationIndex>行业阈值 && 存在门店间距<行业保护距离
    -> "A店与B店间距仅85m, 日均营收￥12K/￥8K, 疑似蚕食"
    处方: 建议关闭低营收门店, 预计年省￥18万租金

16. density-deadzone: POI_RES高密度hex但2000m内无门店
    -> "中关村软件园H3格网居住密度极高, 但2km内无任何门店覆盖"
    处方: 建议考察该区域开店可行性

17. competitor-encroachment: COMP密度 > OWN密度×2
    -> "竞品在你门店周边500m内密度是你自身密度的2.3倍, 市场被侵蚀"
    处方: 列出被侵蚀门店清单

18. market-gap-quantified: whiteSpace非空 && POI_RES>50
    -> "项目东南象限有0.8km²居住区未被覆盖, 约6000户居民"
    处方: 建议在XX街道YY路口增开新店

19. brand-gap: 品牌门店数>5 && 某城市区域无覆盖
    -> "您的品牌在朝阳区有8家店, 但望京3km半径内完全无覆盖"
    处方: 建议望京开店

### 选址优化类 (4条)
20. rent-efficiency: rentFactor<0.3 && footTraffic>0.7
    -> "门店处于高客流低租金区域(异常), 应验证数据或优先续租"
    处方: 标记为战略资产

21. rent-burden: rentFactor>0.8 && footTraffic<0.3
    -> "门店处于高租金低客流区域, 单位客流成本为项目中位数3.4倍"
    处方: 建议评估退租

22. roi-ranking: 多候选点 && 有营收+租金数据
    -> "A候选点预期ROI 18个月(￥3.2万/月), B候选点预期ROI 24个月(￥2.1万/月)"
    处方: 按ROI排序

23. franchise-protection: brandProtection距离 < minDistance
    -> "候选点距同品牌门店仅1200m, 品牌保护距离为3000m"
    处方: 硬过滤或调整候选点

### 运营优化类 (3条)
24. cluster-inefficiency: 聚类数=1 && pointCount>20
    -> "所有23家门店集中在一个聚类, 西南门店距聚类中心8.2km"
    处方: 建议在西南方向设立第二聚类中心

25. delivery-desert: deliveryCoverage<0.2 && POI_RES>50
    -> "3km外卖覆盖仅18%, 但周边有5200户家庭"
    处方: 建议与外卖平台合作或自建配送

26. area-efficiency: areaSqm存在 && 营收/面积比低于项目P25
    -> "门店面积120㎡, 日营收￥5K, 单位面积产出￥41/㎡"
    处方: 面积效率低于项目P25的标记为关注项

## 结构化输出格式 (DecisionAction)

interface DecisionAction {
  id: string;
  category: 'coverage'|'competition'|'site'|'operations';
  priority: 'critical'|'high'|'medium'|'low';
  diagnosis: {
    metric: string;
    currentValue: number;
    threshold: number;
    benchmark?: number;
    benchmarkLabel?: string;
    severity: 'red'|'yellow'|'green';
  };
  prescription: {
    action: string;
    target: { lng: number; lat: number; label: string } | null;
    expectedImpact?: {
      coverageGain?: number;
      overlapReduction?: number;
      revenueImpact?: number;
      costImpact?: number;
    };
    confidence: number;
  };
  evidence: {
    mapView?: { center: [number,number]; zoom: number };
    supportingData: Record<string, any>;
  };
  industryContext?: {
    norm: string;
    exception?: string;
  };
}
