# POI 采集运行手册

## 概述

`backend/src/jobs/poiCollector.ts` 是一个基于高德地图 POI 搜索 API 的公共数据采集器。
它按 H3 六边形网格分批采集周边 POI（便利店、餐饮、药店等），构建数据壁垒核心资产。

## 前置条件

1. **高德 Web 服务 API Key**：需有足够 QPS 配额（免费版约 100 QPS/日，建议接入企业版）
2. **Redis**：用于任务队列管理
3. **PostgreSQL + PostGIS**：`public_poi` 表已通过 init.sql 创建

## 运行方式

### 单次采集（指定区域）

```bash
cd backend
npx ts-node src/jobs/poiCollector.ts \
  --bbox "116.2,39.8,116.6,40.0" \   # 北京城区
  --categories "050000,060000" \       # 餐饮+购物
  --resolution 9                       # H3 分辨率 (~174m)
```

### 定时采集（生产环境）

通过 BullMQ 定时任务：
```
# 在 .env 中配置
POI_COLLECT_CRON=0 2 * * *    # 每天凌晨2点
POI_COLLECT_BBOX=116.0,39.5,117.0,40.2
POI_COLLECT_CATEGORIES=050000,060000,170000
```

## 参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| --bbox | 采集范围 (minLng,minLat,maxLng,maxLat) | 116.2,39.8,116.6,40.0 |
| --categories | 高德 POI 分类码（逗号分隔） | 050000,060000 |
| --resolution | H3 网格分辨率 (0-15) | 9 |
| --delay | 请求间隔毫秒（避免限流） | 200 |

## 高德 POI 分类码参考

| 分类码 | 类别 | 说明 |
|--------|------|------|
| 050000 | 餐饮服务 | 餐厅、小吃等 |
| 060000 | 购物服务 | 商场、便利店等 |
| 070000 | 生活服务 | 美容美发等 |
| 080000 | 体育休闲 | 健身房、公园等 |
| 090000 | 医疗保健 | 医院、药店等 |
| 170000 | 科教文化 | 学校、图书馆等 |

## 注意事项

- `public_poi` 表中存储的是统计聚合后的 POI 密度，**不直接暴露原始商户数据**给前端
- 前端通过 `poi_density` 视图获取聚合统计，保护原始数据资产
- 建议定期采集（月度），保持数据新鲜度
